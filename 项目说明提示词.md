AirMirror Future

============================================================
二、项目的核心问题
============================================================

本项目希望探讨：

“如果未来 RIS（Reconfigurable Intelligent Surface，可重构智能表面）在材料、器件、控制、感知、组网等方面持续进步，电子信息基础设施是否可能从‘可编程网络’进一步演化为‘可编程空间’？”

传统无线系统主要控制：

TX
RX
天线
协议
路由
计算

而传播环境 H 通常被认为是外部给定条件。

RIS 引入：

H -> H(S)

其中 S 是 RIS 的配置状态。

项目的核心思想是：

“让传播环境本身成为一个可计算、可配置、可优化的系统组成部分。”

最终软件应当表现为一个：

“未来电磁空间数字沙盘 / Future Electromagnetic Space Simulator”

而不是普通的 RIS 参数计算器。

============================================================
三、最重要的方法论
============================================================

整个项目必须坚持：

PHYSICS-CONSTRAINED FUTURISM

即：

“物理规律不变，但允许未来器件性能和系统能力显著提高。”

所有仿真都必须遵守基本物理约束，包括但不限于：

1. Maxwell 电磁学基本规律；
2. 波的传播与相位演化；
3. 复电场叠加；
4. 相长/相消干涉；
5. 自由空间传播损耗；
6. 有限孔径效应；
7. 能量守恒；
8. 无源 RIS 不允许凭空产生 RF 能量；
9. 反射效率必须 <= 1；
10. 相位控制存在有限精度；
11. 材料和器件存在损耗；
12. 实际系统存在噪声；
13. 实际 RIS 存在相位误差；
14. 控制存在有限更新时间；
15. 多次传播/反射必须产生额外损耗；
16. 不允许通过人为添加“RIS 增益 +10 dB”一类经验常数来制造展示效果。

未来 RIS 可以假设：

更大的孔径；
更多单元；
更高相位分辨率；
更低损耗；
更快重构；
更好的环境感知；
多 RIS 协同；
更宽带；
更先进的优化算法；
建筑材料融合；
通信、感知、定位融合。

但这些必须通过明确参数进入模型。

任何“未来假设”必须在 UI 或文档中明确标记为：

Future Scenario Assumption

不得把远未来参数描述成当前工程已实现能力。

============================================================
七、基础传播模型
============================================================

必须保留复数相位。

绝对不能只根据距离计算 RSSI。

波数：

k = 2*pi/lambda

lambda = c/f

自由空间直达链路可采用复信道形式：

h_LOS =
sqrt(Gt * Gr) *
lambda / (4*pi*d) *
exp(-j*k*d)

如果存在额外阻挡衰减：

h_LOS *= 10^(-A_block_dB / 20)

接收功率：

Pr = Pt * |h_total|^2

内部可用 W 计算，再转换为 dBm。

如果没有足够模型依据，则允许使用 relative power，
但 UI 必须标为：

“相对接收功率 / Relative Received Power”

不能冒充严格绝对 dBm。

============================================================
八、噪声与 SNR
============================================================

噪声底：

N_dBm =
-174
+ 10*log10(B)
+ NF

其中：

B：带宽 Hz
NF：接收机噪声系数 dB

SNR：

SNR_dB = Pr_dBm - N_dBm

理论容量可用 Shannon：

C = B * log2(1 + SNR_linear)

但 UI 必须明确标注：

“Shannon 理论上界”

不要把它称作真实 Wi-Fi/5G 吞吐量。

============================================================
九、普通墙体与反射
============================================================

墙体使用可配置复反射系数：

Gamma_wall =
rho * exp(j*phi)

要求：

0 <= rho <= 1

第一阶段只实现：

LOS
+
一次墙面反射
+
RIS 路径

即可。

墙体一次镜面反射可采用：

image method

或等价几何模型。

所有路径最终必须在复数域叠加：

E_total / h_total =
h_LOS
+
sum(h_wall)
+
sum(h_RIS)

不能直接把各路径功率相加。

十一、RIS 几何模型
============================================================

RIS 不是简单的“+Gain 方块”。

必须显式建模为有限尺寸孔径。

RISSurface 至少具有：

position: Vec3
yaw / orientation
width
height
nx
ny
phase_bits
reflection_efficiency
frequency_range
update_rate
self_sensing
active
preset_generation

RIS 为竖直矩形平面。

根据：

width
height
nx
ny

生成 nx * ny 个 cell center。

每个 cell 必须具有物理面积：

A_cell =
(width/nx) * (height/ny)

不得让单元总有效面积超过 RIS 实体孔径。

============================================================
十二、RIS 单元反射系数
============================================================

第 n 个单元：

Gamma_n =
sqrt(eta_n) * exp(j*phi_n)

其中：

0 <= eta_n <= 1

对于 passive RIS：

绝对禁止 eta > 1。

未来如实现 active RIS：

必须单独设置：

active = True

并明确引入：

external power
amplification gain
noise figure
power budget

不能偷偷让 passive RIS 产生功率增益。

初版 active RIS 可以只预留接口，不必优先实现。

============================================================
十三、RIS 相位量化
============================================================

支持：

1-bit
2-bit
3-bit
4-bit
以及 continuous / quasi-continuous

1 bit：

{0, pi}

2 bit：

{0, pi/2, pi, 3pi/2}

一般 b-bit：

continuous 时不量化。

============================================================
十四、RIS 路径的物理模型
============================================================

为了兼顾物理合理性和计算速度，采用 aperture-normalized bistatic scattering 模型。

对于每个 RIS cell：

TX -> cell 距离：

d1_n

cell -> RX 距离：

d2_n

入射功率密度来自 TX。

cell 捕获的功率应与：

A_cell

成比例。

可以使用类似下面的复信道贡献：

h_n =
sqrt(
    Gt
    * Gr
    * eta_n
    * A_cell
    * G_cell
    * lambda^2
    /
    ((4*pi)^3 * d1_n^2 * d2_n^2)
)
*
exp(
    -j*k*(d1_n + d2_n)
    + j*phi_n
)

然后：

h_RIS =
sum_n(h_n)

其中 G_cell 可以采用简单的方向图模型。

例如：

G_cell =
max(cos(theta_in), 0)^q
*
max(cos(theta_out), 0)^q

默认：

q = 1

这样可以避免 RIS 向背面不合理地同样强辐射。

如果你认为上述表达存在更规范且仍适合实时系统级仿真的实现，可以改进，但必须：

1. 写清公式；
2. 写进 docs/physics_model.md；
3. 保证能量和孔径尺度关系合理；
4. 禁止使用随意经验增益。

============================================================
十五、理想 RIS 聚焦
============================================================

对于目标 RX，

每个 cell 的总传播距离：

L_n =
d_TX_cell_n
+
d_cell_RX_n

传播相位：

-k * L_n

因此理想补偿相位可以采用：

phi_n =
k * L_n + C

mod 2*pi

符号以程序统一约定为准。

随后：

phi_n = quantize_phase(phi_n, bits)

形成 Physics Focus pattern。

必须用测试验证：

Physics Focus 对简单目标点通常应显著优于随机 pattern 的中位表现。

============================================================
十六、模型误差
============================================================

本项目非常重要的一点：

必须区分：

Controller Model

和

Ground Truth Model

否则“反馈优化”没有意义。

Controller Model：

RIS 控制器认为的世界。

Ground Truth：

仿真的“真实世界”。

Ground Truth 可以加入：

1. wall reflection amplitude error；
2. wall reflection phase error；
3. RIS phase error；
4. RIS efficiency error；
5. TX/RX position error；
6. obstacle position error；
7. measurement noise；
8. device calibration error。

例如：

phi_real,n =
phi_command,n + epsilon_phi,n

epsilon_phi ~ N(0, sigma_phi^2)

测量：

P_measured_dB =
P_true_dB
+
N(0, sigma_measure^2)

所有随机模型必须支持固定 seed，
保证实验可复现。

============================================================
十七、优化算法
============================================================

第一阶段至少实现三种。

------------------------------------------------
Algorithm A：Physics Focus
------------------------------------------------

基于已知几何直接计算理想相位。

优点：

快。

缺点：

对模型误差敏感。

------------------------------------------------
Algorithm B：Feedback Greedy / Coordinate Descent
------------------------------------------------

不知道 Ground Truth 参数。

只允许调用：

measure(pattern)

获取目标 RX 的测量功率。

从某个 pattern 开始。

逐个 cell 或逐个 tile 改变状态。

如果：

objective 提升

则保留；

否则恢复。

对于大规模 RIS，
不要逐个 4096 cell 暴力跑 GUI。

应支持：

tile grouping / optimization granularity

例如：

8x8 tile
4x4 tile
individual cells

------------------------------------------------
Algorithm C：Physics-Guided Feedback
------------------------------------------------

先：

pattern_0 =
Physics Focus

再：

从 pattern_0 开始进行 feedback refinement。

这是整个项目最重要的算法之一。

核心研究思想：

Physics Prior
+
Real Feedback

用物理先验快速初始化，
用反馈补偿模型误差。

============================================================
十八、优化性能优化
============================================================

不要每次评估一个 pattern 都重新计算全部几何。

对固定 TX/RX/RIS：

预计算：

a_n =
传播幅值 *
传播相位等几何项

然后：

h_RIS =
dot(a, Gamma)

对于多个评价点：

建立矩阵：

A.shape = [num_points, num_cells]

然后：

field =
A @ Gamma

Greedy 优化应尽量支持增量更新。

这样即使：

N = 1024 ~ 4096

也能较快运行。

五十二、绝对禁止的实现方式
============================================================

1. “打开 RIS -> 所有区域 +10 dB”；
2. 用人为绘制的圆形热点代替场计算；
3. Future 模式直接乘一个 100 倍系数；
4. 不计算相位；
5. 只计算距离不计算干涉；
6. 多路径功率直接相加；
7. passive RIS efficiency > 1；
8. 为追求视觉效果隐藏损耗；
9. 把 Shannon capacity 称作真实 throughput；
10. 用随机数制造优化成功；
11. 把 Current/Advanced/Future 仅仅做成换颜色；
12. 将没有实现的按钮伪装成可用功能。
